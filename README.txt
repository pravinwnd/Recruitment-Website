RECRUITMENT WEBSITE - VERSION 2

Files:
- index.html: website
- style.css: design
- jobs.js: vacancy data
- script.js: search, filtering and application popup

To add a job:
1. Open jobs.js.
2. Copy an existing job object.
3. Change title, location, type, experience and salary.
4. Save and refresh the website.

The application form is currently a DEMO and does not send data anywhere.
Next step: connect it to Google Forms or another low-cost form service, then add resume upload.
